\# Silos Vision Global Centralizada



Dashboard multiproveedor para revisar Aruba, Citrix, Microsoft 365 y GLPI desde una misma interfaz.



El proyecto está formado por un backend Spring Boot, una base de datos MySQL, un frontend React/Vite y scripts SQL de validación.



Aruba Central es la integración real del proyecto. Citrix, Microsoft 365 y GLPI se simulan desde backend para poder trabajar con históricos, KPIs y escenarios controlados durante el TFG.

dashboard/              Backend Spring Boot

frontend/               Interfaz React + Vite
